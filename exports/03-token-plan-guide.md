# Token Plan 使用指南

Token Plan 是面向个人开发者、企业和团队的 AI 大模型订阅服务。一个订阅即可使用套餐范围内的多种主流模型，并通过 Credit 统一计量。Token Plan 提供个人版和企业版：个人版由购买者本人使用，企业版支持统一购买、分配和管理团队席位。

## 1.Token Plan 企业版

### 1.1 套餐概览

Token Plan 企业版面向企业和团队，提供 Lite 轻量版、Standard 标准版和 Pro 尊享版三个档位，匹配不同使用强度。

#### 1.1.1 产品特点

- **主流模型一站使用：**一个订阅即可使用套餐范围内的多种主流模型，按需切换，无需分别采购和配置。
- **兼容主流 AI 工具：**使用 Token Plan 专属 API Key，可接入支持自定义模型服务的 AI 编程与智能体工具。
- **多档套餐灵活选择：**提供 Lite 轻量版、Standard 标准版和 Pro 尊享版三个档位，覆盖从日常辅助到高频使用的不同需求。
- **订阅用量清晰可控：**支持按月或按年订阅，以 Credit 统一计量，可在控制台查看额度和使用明细。
- **按需组合团队席位：**不同档位席位可按成员使用强度灵活搭配，兼顾使用需求与团队预算。
- **团队订阅统一管理：**管理员可统一分配、回收和升级席位，并查看成员用量；每个席位独享额度并对应一个专属 API Key。

#### 1.1.2 产品定价

选择套餐类型、数量和订阅周期后完成购买。支持按月、按年购买，也可开启连续包月或连续包年。

**席位说明**

席位是 Token Plan 企业版的基础订阅单位，代表一名团队成员的使用名额。管理员将席位分配给成员后，成员可使用一个专属 API Key 调用服务。每个席位仅可绑定一名成员，不支持多人共用。

#### 1.1.5 订阅规则

**购买规则**

- 支持按月或按年购买，订阅在支付成功后立即生效。
- Token Plan 暂不支持使用代金券购买。
- 套餐 Credit 按订阅周期发放；周期结束后，未使用的 Credit 自动清零，不结转至下一周期。

**有效期**

套餐有效期以自然月为单位，自购买成功当日开始计算。示例：1 月 31 日购买 1 个月套餐，于 3 月 1 日 00:00 到期（非闰年）。

**续费规则**

- 支持手动续费和自动续费。月付订阅可续费 1 个月、3 个月或 6 个月，年付订阅每次可续费 1 年；支持多次续费，每次均从原到期日顺延，续费后的最终到期日不得超过当前日期之后 24 个月。
- 开启自动续费后，系统将在到期前 7 天尝试扣款；关闭自动续费不影响当前周期使用，到期未续费后订阅失效。

**席位变更规则**

- 加购席位后立即生效，到期时间与当前企业订阅一致；费用和本周期 Credit 按剩余时间折算。
- 升级按当前订阅剩余周期补缴档位差价，支付成功后立即生效且到期时间不变；额度更新为目标档位对应额度，已使用额度保留，当前周期内不支持降级。

**退款规则**

新购、续费、加购及升级订单支付成功后不支持退款；关闭自动续费不影响当前周期使用。购买前请确认套餐档位、订阅周期和席位数量。

#### 1.1.6 使用须知

- 套餐专属 API Key 仅限本人使用，不得共享或公开泄露。
- 套餐额度用尽后，订阅专用 API Key 将停止服务；如需继续调用，可切换至按量付费 API Key。
- 套餐支持的模型可能随产品升级调整，实际范围以控制台展示为准。

### 1.2 快速开始

企业管理员完成购买、添加成员和分配席位后，成员即可获取接入信息并调用模型。

#### 1.2.1 步骤一：订阅 Token Plan 企业版

1. 进入 [Token Plan 企业版购买页面](#)。
2. 选择订阅周期和套餐档位，填写各档位席位数量，确认订单后完成支付。
3. 支付成功后订阅立即生效。

#### 1.2.2 步骤二：添加成员并分配席位

1. 进入左侧导航的【成员管理】，添加需要使用 Token Plan 的企业成员；已有成员可跳过此操作。
2. 进入【Token Plan > 企业订阅】，在席位管理中选择未分配席位，并将席位分配给对应成员。
3. 每个席位同一时间只能分配给一名成员。分配完成后，该成员可使用席位对应的套餐额度。

1. 已获配席位的成员进入【Token Plan > 我的订阅】。

#### 1.2.4 步骤四：发起首次调用

将以下示例中的 API Key 和模型名称替换为您自己的配置后发起请求。请求中的 `model` 必须是当前套餐支持的模型。

```bash
curl https://api.ai-gateway.com/v1/chat/completions \
  -H "Authorization: Bearer <YOUR_TOKEN_PLAN_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-pro",
    "messages": [{"role": "user", "content": "你好"}]
  }'
```

调用成功后，可在【我的订阅】查看额度变化和使用明细。更多参数和客户端配置方式可查看[模型接口文档](#)和[客户端工具接入指南](#)。

企业管理员可添加成员、分配和回收席位，并查看团队席位的使用情况。

1. 进入左侧导航的[成员管理](#)。
2. 添加需要使用 Token Plan 的企业成员；成员已存在时无需重复添加。
3. 添加完成后，进入【Token Plan > 企业订阅】为其分配席位。

进入【Token Plan > 企业订阅】查看全部席位。企业管理员可按席位状态筛选，并进行分配、回收、升级和查看详情等操作。

### 1.4 常见问题

#### 1.4.1 套餐购买与续费

**个人版和企业版有什么区别，应该如何选择？**

个人版面向个人使用；企业版面向企业和团队，并提供成员与席位管理能力。两者的套餐档位、价格和支持模型保持一致，可根据是否需要团队协作与统一管理选择。

**个人版和企业版可以同时购买吗？**

可以。个人版订阅与企业版订阅相互独立，分别管理套餐额度和 API Key。

**购买后可以退款吗？**

不可以。新购、续费、加购及升级订单支付成功后均不支持退款，请在购买前确认套餐档位、订阅周期和席位数量。

**套餐有效期如何计算？**

套餐有效期以自然月为单位，自购买成功当日开始计算，并在有效期结束后一天的 0 点到期。例如，非闰年 1 月 31 日购买 1 个月套餐，将于 3 月 1 日 0 点到期。

**是否支持提前续费和多次续费？**

支持手动续费和自动续费。月付订阅可续费 1 个月、3 个月或 6 个月，年付订阅每次可续费 1 年；支持多次续费，每次均从原到期日顺延，续费后的最终到期日不得超过当前日期之后 24 个月。

**续费后为什么当前周期的 Credit 没有增加？**

续费只会延长订阅有效期，不会补充当前周期额度。新周期开始后，系统会按套餐规则发放新周期 Credit。

**如何开启或关闭自动续费？**

可在【我的订阅】中开启或关闭自动续费。关闭后不会影响当前周期使用，仅不再自动续订下一周期。

**可以使用代金券购买 Token Plan 吗？**

暂不支持使用代金券购买 Token Plan。

#### 1.4.2 Credit 与用量

**套餐 Credit 会结转到下一周期吗？**

不会。Credit 仅在当前订阅周期内有效，周期结束后未使用额度自动清零。

**套餐 Credit 何时发放和重置？**

套餐 Credit 按订阅周期发放。进入新周期后，系统发放该周期额度；上一周期未使用的 Credit 不会结转。

**额度用完后会怎样？**

套餐额度用完后，订阅专用 API Key 将停止服务，不会自动转为按量计费。如需继续调用，可切换至按量付费 API Key。

**不同模型如何抵扣 Credit？**

单次消耗由模型类型、Token 用量、思考模式及工具调用等因素决定，不同模型及输入、缓存和输出等计费项的单价可能不同，实际消耗以账单和控制台用量明细为准。

**在哪里查看额度和使用明细？**

可在【我的订阅】查看额度变化和使用明细。企业版成员可查看本人用量，企业管理员还可查看各席位及成员的用量。

**升级套餐后，已使用的额度如何处理？**

升级后额度更新为目标档位对应额度，当前周期已经使用的额度会保留，不会重新清零。

**企业版成员是否共享套餐额度？**

不共享。每个席位拥有独立的周期额度，成员使用其获配席位对应的额度。

#### 1.4.3 API Key 与接入

**在哪里获取 Token Plan API Key？**

获配企业版席位后，可在【我的订阅】的配置区域生成或复制订阅专用 API Key，并查看调用所需的 Base URL。

**订阅专用 API Key 和按量付费 API Key 可以混用吗？**

不可以。Token Plan 调用需使用订阅专用 API Key 和对应的 Base URL；按量付费 API Key 不会抵扣套餐 Credit。

**同一个 API Key 可以配置到多个工具吗？**

可以配置到多个兼容工具中，但仅限 API Key 所属用户本人使用，所有调用共同消耗该席位的额度，不得共享或公开泄露。

**重置 API Key 后，旧 Key 还能使用吗？**

不能。重置后旧 Key 会立即失效，请及时更新接口或客户端中的调用配置。

**订阅到期后 API Key 还能继续使用吗？**

不能。订阅到期且未续费后，订阅专用 API Key 将停止服务。

**如何查看支持的模型和工具？**

支持的模型以套餐概览和控制台展示为准；客户端配置方式可查看文档中心的客户端工具接入指南。

**提示 API Key 无效时如何排查？**

请确认 API Key 已完整复制、未被重置、订阅仍在有效期内，并检查是否使用了 Token Plan 对应的 Base URL。

**提示模型不支持时如何处理？**

请确认请求中的 `model` 名称正确，且该模型属于当前套餐支持范围；实际可用模型以控制台展示为准。

#### 1.4.4 成员与席位

**一个席位可以多人共用吗？**

不可以。每个席位同一时间只能分配给一名企业成员，订阅专用 API Key 也不得共享。

**一名成员可以同时拥有多个席位吗？**

不可以。每名成员同一时间只能持有一个 Token Plan 企业版席位。

**如何为成员更换席位？**

先回收该成员当前持有的席位，再为其分配新的未分配席位。

**回收后的席位可以分配给其他成员吗？**

可以。回收后席位恢复为未分配状态，可重新分配给其他企业成员；席位当期剩余额度会保留。

**席位回收后，原成员的 API Key 还能使用吗？**

不能。席位回收后，原成员将无法继续使用该席位对应的套餐额度和订阅专用 API Key。

**禁用成员后，其席位会自动回收吗？**

不会。禁用成员后，其 API Key 将停止调用，但已分配的 Token Plan 席位仍保持占用；重新启用成员后可恢复使用。

**移除成员后，其席位如何处理？**

成员被移出企业后，其已分配的 Token Plan 席位会自动回收并恢复为未分配状态，可重新分配给其他成员。

**企业管理员如何查看成员用量？**

企业管理员可在企业订阅的席位列表查看额度使用进度，并通过【查看用量明细】查看席位记录；也可在【资源统计】中按成员、模型和时间范围分析团队用量。

## 2.Token Plan 个人版

### 2.1 套餐概览

Token Plan 个人版面向个人开发者，提供 Lite 轻量版、Standard 标准版和 Pro 尊享版三个档位，匹配不同使用强度。

#### 2.1.1 产品特点

#### 2.1.5 订阅规则

**购买规则**

- 支持按月或按年购买，订阅在支付成功后立即生效。
- Token Plan 暂不支持使用代金券购买。
- 套餐 Credit 按订阅周期发放；周期结束后，未使用的 Credit 自动清零，不结转至下一周期。

**有效期**

套餐有效期以自然月为单位，自购买成功当日开始计算。示例：1 月 31 日购买 1 个月套餐，于 3 月 1 日 00:00 到期（非闰年）。

**续费规则**

- 支持手动续费和自动续费。月付订阅可续费 1 个月、3 个月或 6 个月，年付订阅每次可续费 1 年；支持多次续费，每次均从原到期日顺延，续费后的最终到期日不得超过当前日期之后 24 个月。
- 开启自动续费后，系统将在到期前 7 天尝试扣款；关闭自动续费不影响当前周期使用，到期未续费后订阅失效。

**升级规则**

升级按当前订阅剩余周期补缴档位差价，支付成功后立即生效且到期时间不变；额度更新为目标档位对应额度，已使用额度保留，当前周期内不支持降级。

**退款规则**

新购、续费、升级订单支付成功后不支持退款；关闭自动续费不影响当前周期使用。购买前请确认套餐档位、订阅周期和购买信息。

#### 2.1.6 使用须知

### 2.3 常见问题

#### 2.3.1 套餐购买与续费

- **个人版和企业版有什么区别，应该如何选择？** 个人版面向个人使用；企业版面向企业和团队，并提供成员与席位管理能力。两者的套餐档位、价格和支持模型保持一致，可根据是否需要团队协作与统一管理选择。
- **个人版和企业版可以同时购买吗？** 可以。个人版订阅与企业版订阅相互独立，分别管理套餐额度和 API Key。
- **购买后可以退款吗？** 不可以。新购、续费及升级订单支付成功后均不支持退款，请在购买前确认套餐档位和订阅周期。
- **套餐有效期如何计算？** 套餐有效期以自然月为单位，自购买成功当日开始计算，并在有效期结束后一天的 0 点到期。例如，非闰年 1 月 31 日购买 1 个月套餐，将于 3 月 1 日 0 点到期。
- **是否支持提前续费和多次续费？** 支持手动续费和自动续费。月付订阅可续费 1 个月、3 个月或 6 个月，年付订阅每次可续费 1 年；支持多次续费，每次均从原到期日顺延，续费后的最终到期日不得超过当前日期之后 24 个月。
- **续费后为什么当前周期的 Credit 没有增加？** 续费只会延长订阅有效期，不会补充当前周期额度。新周期开始后，系统会按套餐规则发放新周期 Credit。
- **如何开启或关闭自动续费？** 可在【我的订阅】中开启或关闭自动续费。关闭后不会影响当前周期使用，仅不再自动续订下一周期。
- **可以使用代金券购买 Token Plan 吗？** 暂不支持使用代金券购买 Token Plan。

#### 2.3.2 Credit 与用量

- **套餐 Credit 会结转到下一周期吗？** 不会。Credit 仅在当前订阅周期内有效，周期结束后未使用额度自动清零。
- **套餐 Credit 何时发放和重置？** 套餐 Credit 按订阅周期发放。进入新周期后，系统发放该周期额度；上一周期未使用的 Credit 不会结转。
- **额度用完后会怎样？** 套餐额度用完后，订阅专用 API Key 将停止服务，不会自动转为按量计费。如需继续调用，可切换至按量付费 API Key。
- **不同模型如何抵扣 Credit？** 单次消耗由模型类型、Token 用量、思考模式及工具调用等因素决定，不同模型及输入、缓存和输出等计费项的单价可能不同，实际消耗以账单和控制台用量明细为准。
- **在哪里查看额度和使用明细？** 可在【我的订阅】查看额度变化和使用明细。
- **升级套餐后，已使用的额度如何处理？** 升级后额度更新为目标档位对应额度，当前周期已经使用的额度会保留，不会重新清零。

#### 2.3.3 API Key 与接入

- **在哪里获取 Token Plan API Key？** 购买个人版后，可在【我的订阅】的配置区域生成或复制订阅专用 API Key，并查看调用所需的 Base URL。
- **订阅专用 API Key 和按量付费 API Key 可以混用吗？** 不可以。Token Plan 调用需使用订阅专用 API Key 和对应的 Base URL；按量付费 API Key 不会抵扣套餐 Credit。
- **同一个 API Key 可以配置到多个工具吗？** 可以配置到多个兼容工具中，但仅限 API Key 所属用户本人使用，所有调用共同消耗该订阅的额度，不得共享或公开泄露。
- **重置 API Key 后，旧 Key 还能使用吗？** 不能。重置后旧 Key 会立即失效，请及时更新接口或客户端中的调用配置。
- **订阅到期后 API Key 还能继续使用吗？** 不能。订阅到期且未续费后，订阅专用 API Key 将停止服务。
- **如何查看支持的模型和工具？** 支持的模型以套餐概览和控制台展示为准；客户端配置方式可查看文档中心的客户端工具接入指南。
- **提示 API Key 无效时如何排查？** 请确认 API Key 已完整复制、未被重置、订阅仍在有效期内，并检查是否使用了 Token Plan 对应的 Base URL。
- **提示模型不支持时如何处理？** 请确认请求中的 `model` 名称正确，且该模型属于当前套餐支持范围；实际可用模型以控制台展示为准。
