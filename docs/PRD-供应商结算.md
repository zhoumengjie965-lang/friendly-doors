**版本**: v1.0  
**日期**: 2026-04-20  
**状态**: 已开发完成  

---

## 1. 需求背景

### 1.1 业务背景
平台需要管理各AI供应商（OpenAI、Anthropic、Azure等）的账单结算流程。运营人员上传供应商提供的账单文件，系统自动解析并与平台内部数据进行匹配核对，最终确认成本完成结算。

### 1.2 目标用户
- **运营人员**：负责上传供应商账单、核对匹配结果、确认成本
- **财务人员**：查看结算报告、导出差异明细

### 1.3 核心目标
1. 支持多供应商账单上传和管理
2. 自动匹配平台数据与供应商账单，识别差异
3. 提供详细的匹配报告，便于异常处理
4. 成本确认后锁定数据，确保财务准确性

### 2.3 账单匹配报告弹窗

#### 2.3.1 弹窗结构
```
┌─────────────────────────────────────────────────────────────┐
│ 账单匹配报告                                            [×] │
├─────────────────────────────────────────────────────────────┤
│ ▌数据概览                                                   │
│ 账单记录总数：          100,000 条                          │
│ 供应商账单总额：        $10,050.000000                      │
│ 精准匹配成功：          99,800 条 (99.8%)                   │
│ 匹配成功总金额：        $9,900.000000                       │
│                                                             │
│ ▌异常待处理                                                 │
│ ┌─────────────────────────────────────────────────────┐    │
│ │ 1. 用量/金额差异 (Mismatched)              150 条   │    │
│ │   平台预估成本：        $9,950.000000               │    │
│ │   供应商实扣金额：      $9,980.000000               │    │
│ │   差异金额：            +$30.000000                 │    │
│ └─────────────────────────────────────────────────────┘    │
│ ┌─────────────────────────────────────────────────────┐    │
│ │ 2. 平台无记录 (Orphaned)                   50 条    │    │
│ │   供应商实扣金额：      $70.000000                  │    │
│ │   差异金额：            +$70.000000                 │    │
│ └─────────────────────────────────────────────────────┘    │
│                                                             │
│ ▌核算结论                                                   │
│ 平台系统预估总成本：    $9,950.000000                       │
│ 本次确认入账成本：      $10,050.000000 (按供应商实扣金额)   │
│ 成本偏差总计：          +$100.000000                        │
├─────────────────────────────────────────────────────────────┤
│              [导出差异明细] [确认成本并入账]                 │
└─────────────────────────────────────────────────────────────┘
```

#### 2.3.2 匹配报告内容

**数据概览**
- 账单记录总数
- 供应商账单总额
- 精准匹配成功（条数 + 百分比）
- 匹配成功总金额

**异常待处理**
1. **用量/金额差异 (Mismatched)**
   - 记录数
   - 平台预估成本
   - 供应商实扣金额
   - 差异金额

2. **平台无记录 (Orphaned)**
   - 记录数
   - 供应商实扣金额
   - 差异金额

**核算结论**
- 平台系统预估总成本
- 本次确认入账成本
- 成本偏差总计
- 提示信息：确认成本后数据锁定

## 3. 业务流程

### 3.1 账单上传流程
```
运营人员登录后台
    ↓
进入【供应商账单管理】页面
    ↓
点击【上传供应商账单】按钮
    ↓
选择供应商、填写账期
    ↓
上传账单文件（必填）
    ↓
上传消耗明细文件（可选）
    ↓
确认上传
    ↓
系统解析文件（状态=解析中）
    ↓
解析完成（状态=已导入/失败）
```

### 3.2 成本确认流程
```
账单状态=已导入
    ↓
点击【查看明细】查看匹配报告
    ↓
分析匹配率和异常数据
    ↓
处理异常（如需要）
    ↓
检查【确认成本】按钮是否可用
    ↓
条件满足（匹配率=100%或无异常）
    ↓
点击【确认成本】
    ↓
状态变更为【已确认】，数据锁定
```

## 4. 状态流转

```
┌──────────┐    上传解析      ┌──────────┐    解析成功      ┌──────────┐
│   初始   │ ───────────────→ │  解析中  │ ───────────────→ │  已导入  │
└──────────┘                  └──────────┘                  └──────────┘
                                    │                              │
                                    │ 解析失败                      │ 确认成本
                                    ↓                              ↓
                              ┌──────────┐                  ┌──────────┐
                              │   失败   │                  │  已确认  │
                              │ (可删除) │                  │ (锁定)   │
                              └──────────┘                  └──────────┘
```

| 状态 | 说明 | 可执行操作 |
|------|------|------------|
| 解析中 | 文件已上传，系统正在解析 | 等待，操作按钮禁用 |
| 已导入 | 解析成功，可查看匹配结果 | 查看明细、导出明细、确认成本 |
| 失败 | 解析失败，文件格式错误或数据异常 | 删除、重新上传 |
| 已确认 | 成本已确认，数据已锁定 | 查看明细、导出明细 |

## 5. 数据模型

### 5.1 BillRecord（供应商账单记录）
```typescript
interface BillRecord {
  id: string;                    // 账单ID
  billFileName: string;          // 账单文件名
  billFileSize: string;          // 账单文件大小
  usageFileName?: string;        // 消耗明细文件名
  usageFileSize?: string;        // 消耗明细文件大小
  supplier: string;              // 供应商名称
  startDate: string;             // 账期开始日期
  endDate: string;               // 账期结束日期
  uploader: string;              // 上传人
  uploadTime: string;            // 上传时间
  status: "parsing" | "imported" | "failed" | "confirmed";  // 状态
  matchRate?: number;            // 匹配率（百分比）
  totalRecords?: number;         // 总记录数
  matchedRecords?: number;       // 已匹配记录数
  diffAmount?: number;           // 用量/金额差异数
  noPlatformRecords?: number;    // 平台无记录数
  // 成本核算字段
  supplierBillTotal?: number;    // 供应商账单总额
  matchedAmount?: number;        // 匹配成功总金额
  platformEstimatedCost?: number;// 平台预估成本
  diffCostAmount?: number;       // 用量/金额差异的成本
  orphanedCostAmount?: number;   // 平台无记录的实扣金额
  totalCostDeviation?: number;   // 成本偏差总计
}
```

## 6. 接口需求

### 6.1 查询供应商账单列表
```
GET /api/supplier-bills
参数:
  - supplier: string (可选)
  - startDate: string (可选, yyyy-MM-dd)
  - endDate: string (可选, yyyy-MM-dd)
  - page: number
  - pageSize: number
返回:
  - total: number
  - list: BillRecord[]
```

### 6.2 上传供应商账单
```
POST /api/supplier-bills/upload
参数:
  - supplier: string (必填)
  - startDate: string (必填)
  - endDate: string (必填)
  - billFile: File (必填)
  - usageFile: File (可选)
返回:
  - success: boolean
  - data: BillRecord
```

### 6.3 删除账单
```
DELETE /api/supplier-bills/:id
参数:
  - id: string (路径参数)
返回:
  - success: boolean
```

### 6.4 确认成本
```
POST /api/supplier-bills/:id/confirm
参数:
  - id: string (路径参数)
返回:
  - success: boolean
  - data: BillRecord
```

### 6.5 获取匹配报告
```
GET /api/supplier-bills/:id/match-report
参数:
  - id: string (路径参数)
返回:
  - success: boolean
  - data: {
      overview: {...},
      anomalies: {...},
      conclusion: {...}
    }
```

### 6.6 导出差异明细
```
GET /api/supplier-bills/:id/export-diff
参数:
  - id: string (路径参数)
  - format: "csv" | "excel"
返回:
  - downloadUrl: string
```

## 8. 异常处理

### 8.1 解析失败场景
| 场景 | 处理建议 |
|------|----------|
| 文件格式错误 | 提示只支持CSV、Excel格式 |
| 缺少必要字段 | 提示缺少字段清单 |
| 数据格式异常 | 提示具体行号和错误原因 |
| 供应商不匹配 | 提示检查供应商选择 |

### 8.2 匹配异常场景
| 场景 | 说明 | 处理方式 |
|------|------|----------|
| 用量/金额差异 | 平台记录与供应商账单不一致 | 人工核对，确认后计入差异成本 |
| 平台无记录 | 供应商账单有记录但平台无对应数据 | 检查是否为脏数据或遗漏记录 |
