---

## 1. 需求背景

### 1.1 业务背景
平台需要为B2B企业客户提供每月的AI服务消费账单，支持运营人员查看、导出和标记账单发送状态。系统每月初自动生成上月账单，运营人员可将账单发送给客户并记录状态。

### 1.2 目标用户
- **运营人员**：负责账单管理、导出、发送给客户
- **财务人员**：查看账单数据进行对账

### 1.3 核心目标
1. 提供清晰的账单列表视图，支持多维度筛选
2. 支持批量操作，提升运营效率
3. 详细的账单明细展示，便于客户理解消费构成
4. 账单状态追踪，掌握发送进度

## 3. 业务流程

### 3.1 账单自动生成
```
定时任务（每月1日 00:00）
    ↓
扫描上月所有企业消费流水
    ↓
按企业+模型维度汇总Token消耗
    ↓
应用合同单价和阶梯折扣计算金额
    ↓
生成账单记录（状态=待结清）
```

### 3.2 运营发送流程
```
运营登录后台
    ↓
进入【用户账单管理】页面
    ↓
筛选/搜索目标账单
    ↓
选择账单（单选或批量）
    ↓
预览账单明细 → 确认无误
    ↓
下载PDF/Excel账单文件
    ↓
通过邮件/其他方式发送给客户
    ↓
点击【标记发送】记录状态
    ↓
账单状态更新为"已发送"
```

## 4. 状态流转

```
┌──────────┐    标记发送      ┌──────────┐    客户确认      ┌──────────┐
│  待结清  │ ───────────────→ │  已发送  │ ───────────────→ │  已确认  │
│ (初始)   │                  │          │                  │          │
└──────────┘                  └──────────┘                  └──────────┘
```

| 状态 | 说明 | 操作权限 |
|------|------|----------|
| 待结清 | 账单已生成，未发送给客户 | 预览、下载、标记发送 |
| 已发送 | 已发送给客户，待确认 | 预览、下载 |
| 已确认 | 客户已确认账单 | 预览、下载 |

## 5. 数据模型

### 5.1 UserBillRecord（账单记录）
```typescript
interface UserBillRecord {
  id: string;              // 账单编号
  enterprise: string;      // 企业名称
  periodStart: string;     // 账期开始
  periodEnd: string;       // 账期结束
  totalAmount: number;     // 账单总额
  currency: string;        // 结算币种
  generatedAt: string;     // 生成时间
  status: "pending" | "sent" | "confirmed";  // 状态
  sentAt?: string;         // 发送时间
  details: UserBillDetail[];  // 明细列表
}
```

### 5.2 UserBillDetail（账单明细）
```typescript
interface UserBillDetail {
  modelName: string;        // 模型名称
  inputTokens: number;      // 输入Token
  outputTokens: number;     // 输出Token
  cacheReadTokens: number;  // 缓存读取Token
  cacheCreateTokens: number;// 缓存创建Token
  inputPrice: number;       // 输入单价
  outputPrice: number;      // 输出单价
  cacheDiscount: number;    // 缓存折扣倍率
  tierDiscount: number;     // 阶梯折扣
  subtotal: number;         // 单项费用
}
```

## 6. 接口需求

### 6.1 查询账单列表
```
GET /api/bills
参数:
  - enterprise: string (可选)
  - period: string (可选, yyyy-MM)
  - status: string (可选)
  - keyword: string (可选)
  - page: number
  - pageSize: number
返回:
  - total: number
  - list: UserBillRecord[]
```

### 6.2 标记账单已发送
```
POST /api/bills/:id/mark-sent
参数:
  - id: string (路径参数)
返回:
  - success: boolean
  - data: UserBillRecord
```

### 6.3 批量下载账单
```
POST /api/bills/batch-download
参数:
  - ids: string[] (账单ID列表)
返回:
  - downloadUrl: string (打包文件下载链接)
```

### 6.4 导出账单PDF/Excel
```
GET /api/bills/:id/export
参数:
  - id: string (路径参数)
  - format: "pdf" | "excel"
返回:
  - downloadUrl: string
```

## 8. 附录

### 8.1 术语表

| 术语 | 说明 |
|------|------|
| Token | AI模型处理的文本单位 |
| 缓存读取 | 命中缓存的token消耗 |
| 缓存创建 | 首次写入缓存的token消耗 |
| 阶梯折扣 | 根据消费金额阶梯给予的商务折扣 |
| 账期 | 账单统计的时间周期（通常按月） |

### 8.2 计算公式

**单项费用计算**:
```
输入成本 = 输入Token × 输入单价 × 阶梯折扣
输出成本 = 输出Token × 输出单价 × 阶梯折扣
缓存读取成本 = 缓存读取Token × 输入单价 × 缓存折扣 × 阶梯折扣
缓存创建成本 = 缓存创建Token × 输入单价 × 缓存折扣 × 阶梯折扣
单项费用 = 输入成本 + 输出成本 + 缓存读取成本 + 缓存创建成本
```

**月度总计**:
```
账单总额 = Σ(各模型单项费用)
```
