## 一、需求概述

### 1.1 背景与痛点

**业务现状**
- 平台每月需向多个AI供应商（OpenAI、Anthropic、Azure等）结算API调用费用
- 当前通过人工导入供应商账单，与平台内部数据手动核对，效率低且易出错
- 差异核对耗时久，影响财务结算周期

**用户痛点**
| 角色 | 痛点 | 影响 |
|------|------|------|
| 运营人员 | 账单文件格式各异，手工导入易出错 | 重复工作，加班严重 |
| 财务人员 | 差异核对没有工具支撑，全靠Excel | 对账周期长，差错率高 |
| 管理层 | 无法实时掌握各供应商成本情况 | 决策缺乏数据支撑 |

### 1.2 需求目标

**核心目标**
1. 实现供应商账单一站式管理，支持多格式文件上传
2. 自动匹配平台数据与供应商账单，智能识别差异
3. 提供可视化差异报告，快速定位问题
4. 建立成本确认流程，确保财务数据准确性

**预期效果**
- 账单处理效率提升 70%
- 差异核对时间从2天缩短至2小时
- 结算差错率降低至 1% 以下

## 二、用户场景

### 场景一：月度账单结算

**角色**: 运营人员小李  
**时间**: 每月5号  
**场景描述**:
> 小李需要处理OpenAI上月的账单。他登录后台，选择供应商和账期，上传CSV格式的账单文件。系统自动解析并显示匹配结果：匹配率99.5%，有3条异常记录。小李点击查看明细，发现是某企业API Key用量统计差异。核对无误后，点击确认成本，系统自动锁定数据并通知财务。

**用户价值**:
- 一键上传，自动解析，告别手工录入
- 异常高亮显示，快速定位问题
- 确认即锁定，避免数据被篡改

### 场景二：差异核对

**角色**: 财务小王  
**时间**: 收到运营确认后  
**场景描述**:
> 小王收到系统通知，某月Azure账单已确认。她打开匹配报告，查看数据概览和异常明细。平台预估成本$50,000，供应商实扣$50,200，差异$200。查看差异明细，发现是一笔缓存费用的计算误差。小王导出Excel差异明细，归档备查。

**用户价值**:
- 差异一目了然，不用反复对比Excel
- 一键导出，满足审计要求
- 数据可追溯，有据可查

### 场景三：多供应商管理

**角色**: 运营主管老张  
**时间**: 每月10号  
**场景描述**:
> 老张需要查看本月所有供应商的结算进度。他进入供应商结算页面，看到各供应商账单状态：OpenAI已确认、Anthropic解析中、Azure待上传。通过筛选快速定位未完成的账单，督促团队尽快处理。

**用户价值**:
- 全局视图，结算进度一目了然
- 状态筛选，快速定位待办事项
- 统一管理，避免遗漏

## 三、功能需求

### 3.1 账单管理列表

#### 功能描述
提供供应商账单的全局视图，支持按供应商、账期筛选，直观展示账单处理状态和匹配情况。

#### 页面布局
```
┌─────────────────────────────────────────────────────────┐
│ 历史上传记录                              [上传账单]     │
├─────────────────────────────────────────────────────────┤
│ [供应商▼]  [开始日期 ~ 结束日期]            [重置]       │
├─────────────────────────────────────────────────────────┤
│ 账单文件      供应商    账期          状态    匹配率 操作 │
│ ┌─────────┐                                          │
│ │账单.csv │  OpenAI   2024-03    [已导入]   99.8%    │
│ │1.2MB    │                              [确认成本]   │
│ └─────────┘                              [查看明细]   │
│                                          [导出明细]   │
├─────────────────────────────────────────────────────────┤
│ 共 5 条记录                                              │
└─────────────────────────────────────────────────────────┘
```

#### 功能说明

| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 账单卡片 | 展示账单文件名、大小、文件类型图标 | P0 |
| 状态标签 | 解析中(蓝)、已导入(绿)、失败(红)、已确认(灰) | P0 |
| 匹配率 | 百分比展示，可点击打开匹配报告 | P0 |
| 操作按钮 | 根据状态动态展示可操作按钮 | P0 |
| 筛选器 | 支持供应商、账期范围筛选 | P1 |

#### 状态与操作对应关系

| 状态 | 可执行操作 | 操作说明 |
|------|------------|----------|
| 解析中 | 查看进度 | 显示解析进度，不可操作 |
| 已导入 | 确认成本、查看明细、导出明细 | 确认成本需满足匹配条件 |
| 失败 | 删除、重新上传 | 展示失败原因 |
| 已确认 | 查看明细、导出明细 | 数据已锁定，不可修改 |

**确认成本条件**：匹配率=100% 或 无异常数据

### 3.2 账单上传

#### 功能描述
提供简洁的账单上传入口，支持选择供应商、填写账期、上传账单文件和消耗明细文件。

#### 交互流程
```
点击"上传账单"按钮
       ↓
弹出上传弹窗
       ↓
选择供应商（必填）
       ↓
选择账期起止日期（必填）
       ↓
上传账单文件（必填，支持拖拽）
       ↓
上传消耗明细文件（选填）
       ↓
点击确认上传
       ↓
系统解析中...
       ↓
解析完成，列表新增记录
```

#### 功能说明

| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 供应商选择 | 下拉选择，支持常用供应商 | P0 |
| 账期选择 | 日期选择器，开始日期≤结束日期 | P0 |
| 文件上传 | 拖拽上传，支持CSV/XLSX/XLS | P0 |
| 格式校验 | 上传前校验文件格式，错误即时提示 | P0 |
| 解析反馈 | 上传成功后显示解析状态 | P1 |

#### 异常提示

| 场景 | 提示文案 |
|------|----------|
| 文件格式错误 | "请上传 CSV、XLSX 或 XLS 格式的文件" |
| 缺少必填项 | "请选择供应商并填写账期" |
| 解析失败 | "文件解析失败，请检查文件格式是否正确" |

│  └─────────────────────────────────────────────────┘   │
│                                                         │
│  ▌异常待处理                                            │

#### 功能说明

| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 数据概览 | 展示总记录数、金额、匹配率等核心指标 | P0 |
| 异常明细 | 分类展示差异类型，支持展开查看详情 | P0 |
| 核算结论 | 汇总成本数据，突出显示偏差金额 | P0 |
| 导出功能 | 支持导出差异明细Excel | P1 |
| 确认操作 | 确认后状态变更，数据锁定 | P0 |

#### 异常类型说明

| 异常类型 | 定义 | 处理方式 |
|----------|------|----------|
| 用量/金额差异 | 同一记录平台与供应商数据不一致 | 人工核对，确认差异原因 |
| 平台无记录 | 供应商账单有记录但平台未采集到 | 检查API Key绑定或数据遗漏 |

## 五、非功能需求

### 5.1 性能需求

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 页面加载 | ≤ 2s | 账单列表页首次加载 |
| 文件解析 | ≤ 30s | 10万条记录的CSV文件 |
| 匹配报告打开 | ≤ 1s | 弹窗展示响应时间 |
| 导出响应 | ≤ 5s | 差异明细Excel导出 |

### 5.2 兼容性需求

| 类型 | 要求 |
|------|------|
| 浏览器 | Chrome 90+, Firefox 88+, Safari 14+, Edge 90+ |
| 文件格式 | CSV, XLSX, XLS |
| 文件大小 | 单个文件 ≤ 50MB |

### 5.3 安全需求

- 账单文件存储需加密
- 成本确认操作需记录审计日志
- 已确认账单不可修改，如需调整需走特殊审批流程

### 5.4 易用性需求

- 操作按钮状态明确，禁用状态有视觉区分
- 异常数据红色高亮，便于快速识别
- 关键操作（确认成本）需二次确认
- 提供操作引导提示
