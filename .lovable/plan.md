
## 在调用日志页面添加角色视图切换器

### 目标
在调用日志页面顶部添加与资源统计页相同样式的胶囊 Tab 角色选择器（普通成员 / 组织管理员 / 企业管理员），切换后动态控制"使用日志"表格列和筛选器。

### 当前情况
- `CallLogs` 组件接收外部传入的 `role` prop，并将其传给 `UsageLogsTab`
- `UsageLogsTab` 已根据 `role` 实现动态列（企业管理员加"组织"列，组织管理员加"成员"列）
- 问题：当前视图角色由外部固定传入，无法在页面内自由切换

### 修改方案

**文件：`src/pages/CallLogs.tsx`**

1. **在 `CallLogs` 主组件中**新增本地 `viewRole` 状态（默认值：外部传入的 `role`）
2. **在页面标题下方、Tabs 上方**插入胶囊 Tab 选择器，样式与 `ResourceStats.tsx` 保持一致：
   ```
   普通成员  |  组织管理员  |  企业管理员
   ```
3. **将 `viewRole`（而非外部 `role`）传给 `UsageLogsTab`**，动态列和筛选器跟随切换

### UI 结构

```text
调用日志
查看 API 调用详情与任务执行记录

[ 普通成员 | 组织管理员 | 企业管理员 ]  ← 新增胶囊选择器

[ 使用日志 | 绘图日志 | 任务日志 ]  ← 原有 Tabs 不变
```

### 技术细节
- 选择器仅影响"使用日志"tab 的列显示与筛选，其他两个 tab（绘图日志、任务日志）不受影响
- 切换角色时重置过滤器状态（通过已有的 `setPage(1)` 逻辑自然处理）
- 代码改动范围最小：只需在主组件加约 20 行，其余逻辑已就绪
