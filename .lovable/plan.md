
# API Key 抽屉优化方案

## 改动目标

1. **布局对齐参考图**：将当前的抽屉表单布局改为左侧 label + 右侧 input 的两栏对齐形式，与图1一致（label 右对齐，input 左侧对齐）
2. **术语替换**：
   - "额度设置" → **"预算设置"**
   - "金额" → **"预算上限"**
   - 相关描述中的"额度"均替换为"预算"
3. **过期时间标注必填**：参考图1，"过期时间"字段加上 `*` 必填标记
4. **模型限制字段**：改为单行输入框（带 placeholder），样式与图1对齐，保留多选功能但改为 tag/pill 形式或多行 input
5. **IP 白名单**：保留多行文本，样式与图1对齐
6. **底部按钮**：改为"取消" + "确定"，并放置在抽屉底部固定区域，与图1对齐

## 技术实现

**只修改 `src/pages/ApiKeys.tsx` 中 Sheet 内容部分（约 lines 504-619）**

- 使用 `grid grid-cols-[auto_1fr]` 或 `flex` 两栏布局，label 固定宽度右对齐
- 将"模型限制"字段改为多选下拉 Select，与图1中单行输入框形态一致
- 将"额度设置"区块标题和内部 label 全部替换为新术语
- 底部按钮区域固定在抽屉底部（`sticky bottom-0` 或保持 flex 在末尾）
- 标题改为"新增API Keys"（新建时）和"编辑 API Key"（编辑时）
- 页面描述中"额度"也一并改为"预算"
