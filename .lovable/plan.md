
# 企业认证区域三状态重设计

## 当前问题
- 未认证和审核中只有一行小字 + 按钮，信息密度低，用户感知不强
- 已认证展示的字段排版是纯列表，缺乏视觉层次
- 没有办法切换三种状态预览（需要实际数据）

## 设计方案

### 三种状态视觉设计

**未认证（uncertified）**
- 左侧：大图标（ShieldAlert，灰色）+ 大号主标题"企业尚未认证"+ 副标题小字说明"完成认证后可享受完整服务权益"
- 右侧：蓝色"立即认证"按钮
- 整体背景：灰色淡底

**审核中（pending）**
- 左侧：大图标（Clock，黄色）+ 大号主标题"认证审核中"+ 副标题"材料已提交，请耐心等待人工审核，通常需 1-3 个工作日"
- 无操作按钮（审核中不可再提交）
- 整体背景：黄色淡底

**已认证（certified）** —— 参考图1样式
- 顶部标题行：认证状态 ● 已认证（绿色点）
- 信息列表：企业注册名称 / 统一社会信用代码 / 法人姓名 / 营业执照（已上传/未上传）
- 底部：管理员可见"重新认证"按钮（次要样式）
- 整体背景：绿色淡底

**被拒绝（rejected）**
- 左侧：大图标（ShieldX，红色）+ 大号主标题"认证未通过"+ 副标题"请检查提交材料后重新申请"
- 右侧：红色"重新认证"按钮
- 整体背景：红色淡底

### 预览三种状态的方式
在 `EnterpriseInfo.tsx` 中，企业认证卡片的右上角（仅开发/演示用，实际根据数据库状态自动切换）不需要额外控件——用户通过实际操作（提交申请 → 审核中；后台改 status → 已认证）来看到各状态。

但用户说"能让我三种状态都能点击看到页面"，这里理解为：需要在当前认证卡片区域内，**临时加一个状态切换器（仅本地模拟）**，让用户在预览中随时点击切换显示效果，方便审查 UI。实现方式：在 CertificationSection 内部 header 区域右上角添加一排小按钮（未认证 / 审核中 / 已认证），点击后覆盖本地显示状态（不影响数据库），用于 UI 预览。

## 技术实现

### 修改 `src/components/CertificationSection.tsx`

1. **新增 previewStatus 本地状态**：初始值 = 数据库真实 status，点击切换按钮时仅改 previewStatus
2. **重构三状态 UI**：
   - 未认证/审核中/拒绝：大图标 + 大字标题 + 副标题（用 `py-6` 保证高度）
   - 已认证：参照图1，列表展示认证信息
3. **顶部 header 加切换按钮组**：三个小 Badge/Button，点击切换预览，当前激活状态高亮

### 样式要点
- 各状态用 `bg-*/5` 或 `bg-*/10` 淡背景区分
- 大图标用 `w-10 h-10`，标题用 `text-lg font-semibold`
- 已认证信息用两列网格对齐（参照图1）
