
## 重构个人信息页

### 目标
删除个人余额卡片和余额预警卡片，重新设计为紧凑的单卡片页面，包含：
1. 姓名（可编辑）
2. 手机号（只读）
3. 邮箱绑定（输入框，暂存本地，后续可扩展）
4. 所在企业-组织-角色（只读信息展示，从 Workspace 传入）

### 修改方案

**`src/pages/Workspace.tsx`**
- 给 `<Profile />` 传入 `enterprise`、`currentOrg`、`role` 三个 props

**`src/pages/Profile.tsx`**
- 接收 `enterprise`、`currentOrg`、`role` props
- 删除余额、预警相关所有代码
- 重排版：单张卡片内用两列网格排布字段（手机号、姓名、邮箱、所在企业信息）
- 布局更紧凑：字段分组为「账号信息」+ 「所属企业」两个小节，无需多个大卡片
- 邮箱字段：本地 state 存储，暂不对接后端（提示"邮箱用于接收通知"）

### UI 示意
```text
┌────────────────────────────────────────────┐
│  👤 个人信息                               │

│  手机号   138****5678  (只读)              │

│  ─────────────────────────────────────────│
│  所属企业                                  │
│  企业     AI科技有限公司                    │

│  角色     组织管理员                        │

```

无企业时「所属企业」部分显示"暂未加入企业"。
